# Verify — Retired

The signed verification portal experiment (static site + published
trust/registry) was fully removed. Authenticity is by manual BRGY-ID
lookup: scan the card QR (unsigned 7-key JSON, see
`Documents/QR_PII_README.md`), read its `id`, and search that
`resident_id` in the app or the Excel export.

This folder is kept for operator-side files only. Anything
registry/trust-shaped left here from the experiment window is stale —
do not upload or rely on it.
